# ООО «СК Держава» — учёт и ремонт промышленного оборудования

Учебное веб-приложение на Flask и PostgreSQL для трёх ролей: администратор, инженер и клиент.

## Структура базы

Приложение работает с пятью таблицами: \`clients\`, \`employees\`, \`statuses\`, \`equipment\`, \`requests\`. Схема находится в \`schema.sql\`.

**Важно:** \`schema.sql\` содержит DROP TABLE и полностью удаляет данные в одноимённых таблицах. Выполняйте его только если действительно хотите пересоздать базу.

## Возможности

- Вход клиентов и сотрудников по email и паролю; регистрация клиентов.
- Отдельная административная учётная запись из локального \`.env\`.
- Кабинеты по ролям, список клиентов и сотрудников.
- Учёт оборудования, гарантийных сроков и серийных номеров.
- Создание заявок клиентом только на собственное оборудование.
- Назначение инженера, изменение статусов и расчёт стоимости.
- Просмотр заявок, отчётов и профиля.
- Хеширование паролей Werkzeug. Старые демонстрационные пароли в открытом виде автоматически хешируются при первом успешном входе.

## Установка Windows

1. Создайте виртуальное окружение:
   \`py -m venv .venv\`
2. Установите зависимости:
   \`.\.venv\Scripts\python.exe -m pip install -r requirements.txt\`
3. Скопируйте \`.env.example\` в \`.env\` и заполните параметры PostgreSQL, пароль администратора и секретный код регистрации сотрудников.
4. Убедитесь, что в PostgreSQL создана база \`derzhava\` и в ней выполнен SQL для пяти таблиц.
5. Запустите:
   \`.\.venv\Scripts\python.exe app.py\`
6. Откройте http://127.0.0.1:5000

## Настройка

В \`.env\` укажите \`DB_NAME=derzhava\`, имя пользователя и пароль PostgreSQL. Для администратора задайте \`ADMIN_EMAIL\` и уникальный \`ADMIN_PASSWORD\`. Секреты не публикуйте в GitHub.

## Роли

- Администратор: полный доступ к разделам и заявкам.
- Инженер: просмотр доступных/назначенных заявок, работа с заявками и оборудованием.
- Клиент: своё оборудование, создание и отслеживание заявок.

## Проверка подключения

Откройте http://127.0.0.1:5000/health. При успешном подключении будет JSON со статусом \`ok\`.
