# Система учёта ремонта промышленного оборудования

Веб-приложение для ООО «СК Держава» на Flask и PostgreSQL.

## Роли пользователей
- Администратор — управление системой.
- Инженер — обработка заявок, диагностика и учёт ремонта.
- Клиент — регистрация оборудования, подача заявок и просмотр их статусов.

## База данных
Используется PostgreSQL, база данных `derzhava`. Схема и тестовые данные создаются отдельно и уже подготовлены.

## Технологии
- Python и Flask
- PostgreSQL
- psycopg2
- HTML и CSS

## Запуск
Инструкции по установке зависимостей, настройке переменных окружения и запуску приложения будут добавлены вместе с исходным кодом.
